WARMAP CONQUEST v18 - КЛАНЫ

1. Создайте проект на https://supabase.com/
2. В Supabase включите Authentication -> Anonymous Sign-Ins.
3. В SQL Editor выполните целиком файл supabase_setup.sql из этого архива.
4. Скопируйте Project URL и Publishable key (sb_publishable_...).
   Никогда не вставляйте service_role / secret key в приложение.
5. В WARMAP откройте вкладку "Клан", вставьте URL и Publishable key, нажмите "Сохранить и подключить".
6. Введите имя, создайте клан. После размещения WARMAP на HTTPS кнопка "Поделиться ссылкой" даст готовую ссылку другу.
